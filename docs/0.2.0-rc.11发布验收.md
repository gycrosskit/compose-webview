# WebView 0.2.0-rc.11 发布与验收

2026-10-07：在已发布 rc.10 主线基础上发布本次验证码接入边界补丁，保留 OhosWebViewDataCleaner。Maven、Kuikly iOS Git Pod、OHPM/Release HAR 均使用不可变版本 0.2.0-rc.11，HAR 精确配套 system-actions-native 0.2.0-rc.4 与 Kuikly Render 2.28.0。

## 组件边界

- 命名业务脚本沿用手动 JS 执行的来源约束：可信 HTTPS，或明确 pageBridgeEnabled 的初始 HTTP(S) 同源主文档。HTTP 不进入高权限 trust，文件/媒体与真实 frame、nonce、文档代次门禁保留。
- navigationPolicy.allowedUrls 按完整 URL 原字符串同步检查主文档，与 scheme、origin 和 blockedRules 组合；默认空，不影响子资源，不归一化路径、查询、fragment 或默认端口。
- 补齐 CMP/Kuikly iOS 的 WKWebView/scrollView 及 OHOS Web 的透明背景，没有新增背景配置或业务 Bridge。
- 宿主保留业务覆盖层、协议版本、单次配置、challengeId/阶段关联、JSON 编码、取消/销毁及短信接口。Android 不支持 document-start 时保留晚注入兼容；需要早期 facade 的业务在协议失败或超时后停止，不能跳过验证码。单次早期 READY 可暂存，FirstContentVisible 后冲刷以等待 Android nonce。

## 验证范围

合入 rc.10 前已通过 36 项定向测试、CMP/Kuikly Android/iOS Simulator/OHOS 编译、真实 Render 2.28.0 iOS 原生最终链接/Swift API、iOS26.3 Simulator Native wire/同步导航/WebKit 规则、生产 Kotlin 生成脚本 VM、实际 HAR 契约和独立本地 HAR 公开 API 消费。旧 H5 的无网络 VM 验证 READY/V2、nonce 后冲刷、单次配置与终态；未调用腾讯验证码或短信后端。

发布准备重新执行合入后的源码回归、Maven 全变体归档检查、HAR assemble/prepublish/实际产物消费者，并将归档 SHA-256 冻结到 release-checksums.txt。标签与 Release 资产发布后再执行干净 Maven/Git Pod/Release HAR 消费，OHPM 审核通过后需实际查询并空缓存安装。CI 的远程 PR 基线不是本候选交付证明，正式 Release 验证使用精确 tag。

真实腾讯验证码、SendSMS3 后端回执、三端视觉/触摸、最低系统与设备内核行为未验收。发布成功或编译通过均不等于这些业务场景通过。
