## 实现与源码回归

Android Kuikly 与 OHOS 隐藏文档仍初始化；恢复仅恢复原实例活动状态与 OHOS Bridge 端口，不 reload。初始化保留 JavaScript、可信主文档、owner/render、销毁与故障门禁；业务消息、权限、选择器及显式 JS 回执仍由 native 可见性与 generation 撤销。OHOS DOM_READY 在 document-start 注册 DOMContentLoaded，结束事件兜底，命名脚本每文档一次，`__proto__` id 也不会绕过去重。

OHOS bootstrap 隐藏时拒绝新消息并清除已排队业务消息；恢复先同步 JS visibility 再握手。revision 拒绝晚执行 hide，新导航撤销旧 visibility pending，避免新文档永远不能握手。JS 状态只做队列清理，授权仍由 native origin/visible/generation 检查。

Android 直接生产 GYWebViewNative 的 Robolectric 3 项回归通过；仅系统 WebView/旧内核使用替身。OHOS Node 转译真实 GYWebView.ets、执行真实生成脚本与 bootstrap，覆盖隐藏完成、DOM_READY、去重、队列清空、乱序、导航与旧 Controller；系统 API 使用替身。独立只读复审无阻断，diff 检查通过。iOS Native WKUserScript/didFinish 原有隐藏初始化无需修改。
