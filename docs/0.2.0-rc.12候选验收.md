## 行为与原生配对

- CMP 增加 `goForward()`、快照 `canGoForward`、`goBack(callback)` 和 `exitFullscreen(callback)`。返回先退出全屏，再返回原文档历史；同步 iOS `goBack()` 的 true 表示已受理，回调交付最终结果。
- CMP / Kuikly iOS 通过同一 Kotlin 脚本来源及现有生成器等待标准或 prefixed DOM/video 全屏事件，1.5 秒有界超时清理监听；不能将发出 JS 当作退出成功。
- owner/document 结束交付一次 false，迟到结果不再成功，取消不回退新文档历史。取消回调同步绑定新 owner 时，旧导航、解绑及 coordinator attach 不覆盖新 owner；真实 iframe 不能伪造当前主页面全屏状态。
- ObjC 脚本改变，Git Pod 必须使用 rc.12 / Render 2.28.0。OHOS ETS 未变，保留 Web HAR rc.11 与 system-actions-native HAR rc.4，不为版本数字一致重发旧产物。
