# WebView 开发与验证

源码构建与第三方远程安装是两个入口。日常接入见 [README](../README.md) 和 [接入指南](接入指南.md)。以下命令从仓库根目录执行。

工具链：Kotlin `2.2.21-1.0.0`、Kuikly `2.28.0-2.0.21-ohos`、CMP `1.10.3`。构建和设备验收分开记录；不要仅凭 KLIB 或 HAR 编译成功就删除应用中的旧组件接线。

AndroidX Activity 会传递稳定性注解包，该包不含 Compose UI 或执行运行时；独立消费者的门禁仅放行这两个注解模块。其他 Compose UI/runtime 依赖仍会使 Kuikly 验证失败。

本地 Maven 打包执行 `bash scripts/package-maven.sh`。JitPack 使用 macOS 预构建归档和 SHA-256 校验；`release-checksums.txt` 保存不可变标签的真实归档校验值。远程消费者使用 `-PremoteOnly -PwebViewVersion=0.2.0-rc.3`，该模式仅从 JitPack 读取本组件。HAR 的 ohpm 审核状态须查询 registry 并实际安装确认；同标签 GitHub Release 的 HAR 可用于审核期间的远程预发布验收。

详细结果见 [VALIDATION](../VALIDATION.md) 与 [HAR 验证](../ohos/VERIFICATION.md)。Maven、iOS 原生 Pod、OHPM HAR 各自验收；已公开的 `@gycrosskit/webview@0.2.0-rc.2` 可从 Registry 安装，GitHub Release HAR 下载不等于 Registry 安装。

Kuikly 独立消费者最终链接时，device 与 simulator 分别传 `-PrenderFrameworkDir` 和 `-PsimRenderFrameworkDir`，值为相应 `OpenKuiklyIOSRender.framework` 的父目录；只提供 device 搜索路径不能证明 simulator 链接。
