## 平台证明范围

Apple 的公开 `WKUIDelegate.runOpenPanelWithParameters` 从 iOS18.4 才支持原生文件拦截，见 [Apple API 文档](https://developer.apple.com/documentation/webkit/wkuidelegate/webview(_:runopenpanelwith:initiatedbyframe:completionhandler:))。本库仍以 iOS15 为最低常规网页版本；15～18.3 开启受控 chooser 明确拒绝并发送 Unsupported。DOM accept/capture 只提供有界的界面提示；旧系统 DOM 默认上传拦截不能声称原生安全隔离。视频沿用 UIKit 的 MOV，仅接受 MP4 时拒绝，不能改名假装转码。

IPv6 精确来源按浏览器 [URL Standard](https://url.spec.whatwg.org/#concept-ipv6-serializer) 规范化，保留有效自定义端口；mapped IPv4 转成十六进制组，展开/压缩表示属于同一来源。DNS HostSuffix 仍按标签边界匹配且不收窄既有端口契约，双终点及内部空 DNS 标签拒绝。AndroidX 的 [allowedOriginRules 官方合同](https://developer.android.com/reference/androidx/webkit/WebViewCompat#addWebMessageListener(android.webkit.WebView,java.lang.String,java.util.Set%3Cjava.lang.String%3E,androidx.webkit.WebViewCompat.WebMessageListener))规定省略 HTTPS 端口只匹配443，不能表达任意端口。后缀策略注册全来源包装；真实包装在执行业务体前先检查主 frame 和可信 HTTPS/DNS 后缀，Bridge 的原生来源门禁不变。`verification/early-scripts` 调用已编译的生产 generator，再用 Node 执行其真实脚本，覆盖8443/65535、HTTP、相似后缀与子 frame。

OHOS fileSelector 没有来源 frame 或独立 gesture 信息，只能证明当前可信且就绪主文档，不能把它称为真实 frame 授权。回归运行生产控制器/原生源码，系统弹窗/权限/相机可由平台替身隔离；真实 UIKit JPEG 编码和磁盘读写是单独证据，不代表真机相机录制或 H5 HTTP 上传。第三方 SDK 内部、外部 system-actions 实现、宿主业务与三端真机验收不属于本清单；后者仍必须单独完成。结果与失败记录见 [候选验收](0.2.0-rc.9候选验收.md)。

同一生产 CMP controller 的 K/N test.kexe 已打包为真正 UIApplication，在 Simulator 真实 UIWindow/WKWebView 首航完成与输入聚焦后打开原生 DocumentPicker。真实 UTType JPEG/Image 与 MOV/Movie conformance、AVAssetWriter MOV、文件保留/取消/文档撤销均通过；仅接受 MP4 时拒绝 MOV。该 App 测试是独立平台证明，不由 standalone runner 或 Objective-C 同功能测试替代。当前覆盖 111 个生产/配置/命令文件、512 个入口声明与 32 个测试/fixture；190 个归档 Kotlin source entries 与最终源码逐字节相同。
