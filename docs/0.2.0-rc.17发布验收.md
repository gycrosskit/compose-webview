# 0.2.0-rc.17 发布验收与边界

本版 Maven / GYWebView Git Pod 坐标为 `0.2.0-rc.17`；公开状态以[对应 Release](https://github.com/gycrosskit/compose-webview/releases/tag/0.2.0-rc.17)及 CI 收据为准。OHOS 原生源码未改，沿用 HAR `0.2.0-rc.14` 及 system-actions-native `0.2.0-rc.4`；[WebViewNative.har 仍从 rc.16 Release 下载](https://github.com/gycrosskit/compose-webview/releases/download/0.2.0-rc.16/WebViewNative.har)，rc.17 不重复上传旧 HAR。旧标签、归档及版本不覆盖。

## 修复

- CMP Android 在创建原生 WebView 时设置 `MATCH_PARENT`，保留 Compose 父布局约束。旧 Chromium 在 `WRAP_CONTENT` 下可能将 CSS viewport 高度归零，导致 `100vh` 蒙版不可见；Kuikly Android 的既有布局策略无需修改。
- CMP iOS 在系统支持 `setInspectable:` 时按最终 Kotlin/Native binary 的 `Platform.isDebugBinary` 设置检查能力；Kuikly iOS 16.4+ 按 `DEBUG` 设置，新建 WKWebView 在非 Debug 构建显式关闭检查能力。

## 远程门禁

Source regression 的源码归档入口为 `gh workflow run regression.yml --ref codex/webview-debug-policy -f package_maven=true`。它保留完整 Android / Native / 契约检查，另以同一次固定 Renderer 构建运行 Kuikly Objective-C 的 Debug / Release 真实 wire。实际 inspectable 断言未执行或档位不符均不能通过。

Native 检查后复用 `scripts/package-maven.sh` 生成 Maven 冻结归档，严格检查 17 publications、平台变体、精确内部依赖及哈希 sidecar。归档、SHA256SUMS 和来源收据作为 Actions artifact 上传；只有整次运行成功，才冻结真实 checksum 并推进 PR。归档收据本身不代表其他并行 job 成功。

发布后由 Release validation 检查冻结归档及全部公开 JitPack 文件，并从精确远程坐标编译 Android、iOS、OHOS 消费者。rc.17 已纳入 KuiklyCompose、pageChannels、navigation 探针。Git Pod 另安装精确标签、构建真实 Simulator framework，核对 Pod lock 的 git/tag/version，以及对应提交的生产源文件集合和字节摘要。

发布后补充的公开验收收据使用 Release asset [`release-verification.json`](https://github.com/gycrosskit/compose-webview/releases/download/0.2.0-rc.17/release-verification.json)：记录最终标签 SHA、源码/归档 run 与真实归档 SHA-256、公开消费 run ID，以及 JitPack、Git Pod、OHOS KLIB 的核验结果。文件和对应成功 CI 缺失时，不据本页的坐标或安装示例认定已发布、已验收。

2026-10-10 源码与归档验收：[run 38042220337](https://github.com/gycrosskit/compose-webview/actions/runs/38042220337) 的 changes / contracts / android / native 全部成功，构建源码为 `8b3d42109bcb41f360a196620919a7cc6a407ccf`。97 项实际 Native 测试零失败、错误或跳过；两档真实 wire 均执行原有回归并产生对应的 `PASS: Native inspectable policy DEBUG=0/1`。Loopback 页面 fixture 直接绑定数值地址，避免启动时不必要的反向 DNS；契约测试实际请求 HTTP 页面并覆盖该路径。

该 run 生成的冻结 Maven 归档为 2,171,269 bytes，SHA-256 为 `3426164f50f5869a373d76991f0538aaa3865fb68162488731d8c1fcd2532864`。17 publications 的实际文件、哈希 sidecar、POM 许可证、精确内部依赖及平台变体均通过检查。归档构建 SHA 与之后包含文档/checksum 的最终标签 SHA 分别记录；发布前必须核对两者只有文档和冻结 checksum 的差异，禁止用旧归档承载新增源码或配置。

## 宿主验收

宿主必须消费实际发布坐标，核对旧 WebView 97 与当前内核的有界区域、长页滚动、0 尺寸隐藏后恢复，以及真实 `100vh` / 蒙版表现。不得使用源码替换、mavenLocal 或业务 CSS 兜底代替组件发布验收。

Objective-C 的 Debug / Release wire 不代表 CMP 最终 binary 的运行证明；Git Pod framework 构建不代表 UIKit App 或真机运行。CMP 最终 Debug / Release 检查能力、宿主业务及设备验收仍须分别记录。
