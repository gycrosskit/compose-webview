# 0.2.0-rc.17 发布验收与边界

状态：未发布候选。计划 Maven / GYWebView Git Pod 使用 `0.2.0-rc.17`，OHOS 原生源码未改，沿用 HAR `0.2.0-rc.14` 及 system-actions-native `0.2.0-rc.4`。旧标签、归档及版本不覆盖。

## 修复

- CMP Android 在创建原生 WebView 时设置 `MATCH_PARENT`，保留 Compose 父布局约束。旧 Chromium 在 `WRAP_CONTENT` 下可能将 CSS viewport 高度归零，导致 `100vh` 蒙版不可见；Kuikly Android 的既有布局策略无需修改。
- CMP iOS 在系统支持 `setInspectable:` 时按最终 Kotlin/Native binary 的 `Platform.isDebugBinary` 设置检查能力；Kuikly iOS 16.4+ 按 `DEBUG` 设置，新建 WKWebView 在非 Debug 构建显式关闭检查能力。

## 远程门禁

候选 Source regression 的手动入口为 `regression.yml --ref codex/webview-debug-policy -f package_maven=true`。它保留完整 Android / Native / 契约检查，另以同一次固定 Renderer 构建运行 Kuikly Objective-C 的 Debug / Release 真实 wire。实际 inspectable 断言未执行或档位不符均不能通过。

Native 检查后复用 `scripts/package-maven.sh` 生成 Maven 冻结归档，严格检查 17 publications、平台变体、精确内部依赖及哈希 sidecar。归档、SHA256SUMS 和来源收据作为 Actions artifact 上传；只有整次运行成功，才冻结真实 checksum 并推进 PR。归档收据本身不代表其他并行 job 成功。

发布后由 Release validation 检查冻结归档及全部公开 JitPack 文件，并从精确远程坐标编译 Android、iOS、OHOS 消费者。rc.17 已纳入 KuiklyCompose、pageChannels、navigation 探针。Git Pod 另安装精确标签、构建真实 Simulator framework，核对 Pod lock 的 git/tag/version，以及对应提交的生产源文件集合和字节摘要。

源码 CI、冻结归档 SHA、PR、最终不可变标签和公开消费结果均待实际执行后填写；当前轻量脚本检查不能替代这些门禁。

## 宿主验收

宿主必须消费实际发布坐标，核对旧 WebView 97 与当前内核的有界区域、长页滚动、0 尺寸隐藏后恢复，以及真实 `100vh` / 蒙版表现。不得使用源码替换、mavenLocal 或业务 CSS 兜底代替组件发布验收。

Objective-C 的 Debug / Release wire 不代表 CMP 最终 binary 的运行证明；Git Pod framework 构建不代表 UIKit App 或真机运行。CMP 最终 Debug / Release 检查能力、宿主业务及设备验收仍须分别记录。
